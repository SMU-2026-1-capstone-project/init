# ADR-0005: 관리자 목록/검색에 QueryDSL을 동적 쿼리 계층으로 채택

작성일: 2026-07-31 (구현 완료 2026-08-07)
상태: Accepted
근거 문서: [`../decisions/querydsl-adoption.md`](../decisions/querydsl-adoption.md)

## Context

이 프로젝트에는 동적 쿼리 빌더 계층이 전혀 없었다(QueryDSL·Criteria API·`Specification` 전부 0건). 남은 요구사항 8개를 코드 기준으로 감사하니, 필터·정렬 조합이 런타임에 결정되는 요구는 **관리자 대시보드 목록/검색 하나뿐**이었다 — 나머지는 조건이 고정이거나(파생 쿼리로 충분) 아예 쿼리가 없는 프론트 영역이었다. 즉 이 결정은 사실상 기술 선택이 아니라 "관리자 페이지를 만들 것인가"라는 기능 결정으로 환원됐다.

## Decision

**QueryDSL을 동적 쿼리 계층으로 채택**하고, 첫 적용처는 관리자 회원/세션 목록(필터·가변 정렬·페이징)으로 한정한다. 같은 화면 안에서도 성격별로 도구를 가른다 — 조건 고정 통계 위젯은 JPQL/native, 단건 상세 조회는 파생 쿼리, **런타임 조건 조합이 실제로 있는 목록/필터만** QueryDSL. `JpaSpecificationExecutor`(`Specification`) 병용은 배제한다 — 조건 개수와 무관하게 동적 조회 도구를 하나로 통일한다. Criteria API 직접 사용은 어느 시나리오에서도 채택하지 않는다.

## Consequences

- 얻는 것: 목록 쿼리와 총건수 쿼리가 같은 WHERE·조인 조립 함수를 공유해, "전체 N건"과 실제 페이지가 어긋나는 구조적 버그(파생 쿼리·JPQL을 두 벌 유지할 때 벌어지는 고전적 문제)를 원천 차단한다. 구현 중 더 센 근거가 드러났다 — 검색어 유무에 따라 `FROM` 절 자체(조인 유무)가 바뀌는 쿼리는 파생 쿼리로는 표현 불가능하고 JPQL은 쿼리를 두 벌 써야 하는데, QueryDSL은 `if`로 `.join()` 하나 더하는 것으로 끝난다 — 채택 근거가 "동적 WHERE"에서 "동적 조인"으로 옮겨갔다.
- 감수하는 것: **성능 이득이 아니다** — 실측 결과 Hibernate가 결과에 안 쓰이는 to-one 조인을 SQL 생성 단계에서 이미 제거해, 조인을 명시하든 안 하든 글자 그대로 같은 SQL이 나갔다. QueryDSL이 주는 건 표현력이지 최적화가 아니다. 조인과 WHERE 조건의 짝은 여전히 사람이 맞춰야 한다(자동 검증 없음) — 조건을 하나 늘리면서 대응하는 조인을 안 고치면 "참조는 하는데 조인이 없는" 쿼리가 만들어질 수 있다. 정렬 컬럼 화이트리스트도 QueryDSL이 자동으로 보장하지 않는다 — `PathBuilder`로 요청값을 경로로 만들면 여전히 인젝션 지점이 될 수 있어 별도 화이트리스트가 필요하다.
- 다음에 영향받는 결정: 이 결정이 뒤집히는 조건을 명시해뒀다 — 관리자 화면 필터가 1~2개로 확정되면(당시 §9 선결 과제) QueryDSL의 근거가 사라지고 `Specification`으로 충분해진다. 실제로는 필터 5개(회원)·4개(세션)로 확정돼 조건이 유지됐다. 리포트 목록의 keyset 페이징 신설은 이 결정과 별개로 여전히 열려 있다.

## Alternatives considered

- Criteria API 직접 사용 — 타입 안전성은 QueryDSL과 비슷하게 얻지만 문법이 장황하고 Q타입 같은 코드 생성 이점이 없어 어느 시나리오에서도 권하지 않는다.
- `JpaSpecificationExecutor`(`Specification`) 병용 — 조건 개수가 적은 화면엔 더 가볍지만, 동적 조회 도구가 둘이 되면 "이건 QueryDSL로, 저건 Specification으로" 판단 비용이 생긴다. 조건 개수와 무관하게 QueryDSL로 통일하는 쪽을 택했다.
- 파생 쿼리(메서드 이름) 또는 `@Query` JPQL 두 벌 유지 — 필터 조합이 늘수록(필터 5개 → 32가지, 정렬 3개를 곱하면 96가지) 조합 폭발이 나고, 목록·총건수 쿼리가 어긋나는 위험을 구조적으로 못 막아 기각.
