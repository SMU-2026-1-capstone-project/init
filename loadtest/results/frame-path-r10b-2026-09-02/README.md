**핸들러 슬롯 개수**가 아니다.

### 🔴 판 안에서 처리량이 26% 드리프트했다 — 그런데 팔 판정은 안 흔들렸다

원 순서대로 RPS: 276.67 → 274.64 → 275.25 → 282.2 → 281.32 → 282.08 → **301.31** → **345.44** →
**346.17** → **345.32**. 팔과 무관하게 뒤로 갈수록 오른다(+26% 후반부). 이게
[[project_concurrent_sessions]] 같은 외부 교란인지, 대상 박스의 워밍업(캐시·JIT류 효과)인지는
**미검증**이다.

**라틴 방격이 정확히 이걸 막으려고 있던 장치다** — 세 팔의 본판 3개씩이 각각 초반·중반·후반에
정확히 하나씩 있어서(평균 위치 5.0, 셋 다 동일), 드리프트가 팔 평균에 **똑같이** 실렸다. 이
배열이 아니었으면(예: 팔당 몰아서 3연속) 이 라운드는 「핸들러 동시성이 처리량을 26% 올린다」는
완전히 틀린 결론을 냈을 것이다.

## 4. 🔴 깨진 채로 남은 것 — 원격 CPU 계측 완전 실패

`cpu_remote.avg_vcpu` 가 **10판 전부 `None`**이다(버림판 포함 1판만 `0.0`, 나머지 9판은
`None`) — "일부만 실패"가 아니라 **사실상 통째로 작동 안 했다.** 판 시작·끝
`/proc/<pid>/stat`를 SSH로 두 번 읽는 설계였는데, 그 읽기가 판마다 실패했다는 뜻이다
(원인 미조사 — PID 못 찾음인지, SSH 응답 파싱 실패인지 갈라내지 않았다).

**처리량·지연 판정에는 영향이 없다** — §2의 결론은 이 계측과 무관하게 성립한다. 다만 「대상
CPU가 5→20에서 실제로 안 올랐다」는 이 판이 답을 못 준다 — RPS·지연이 안 움직였다는 것으로
**간접 추론**할 뿐이다. 이슈로 등록([아래 §6]).

## 5. 🔴 실행 코드가 커밋 라벨과 다르다 — 재현성 경고

`MANIFEST.txt`·`ai_venv_conditions.txt` 둘 다 커밋을 `bb0a8e54`로 남겼지만, **실제로 돈
코드는 그게 아니다.** 리허설 중 발견된 원격 부팅 버그 둘(SSH `nohup` 응답 미분리·
`--bind` 원격 자동전환)을 **박스 위에서 직접 패치**한 뒤 본판을 돌렸고, 그 패치를 로컬
저장소에 반영해 커밋한 것은 `42a0d927`다 — 박스는 `git pull`을 다시 한 적이 없어 자기
라벨(`bb0a8e54`)이 그대로 남았다.

**즉 이 라운드를 재현하려면 `42a0d927`(또는 그 이후)를 받아야 한다 — `bb0a8e54`로는
원격 모드가 온전히 안 돈다.** `arms_run1.json`의 `remote_target` 필드가 실제로 채워져
있고 결과가 정상 도출된 것으로 보아 실행 코드 자체는 맞았다고 판단하지만, **박스 안에서
`git rev-parse HEAD`만 보고 "이 커밋으로 재현된다"고 믿으면 틀린다** — 이 프로젝트에서
처음 걸린 사례라 기록해 둔다.

## 6. 이 라운드가 남긴 것

**닫힌 것**

- **R10-b의 원 질문** — `GRPC_MAX_WORKERS`는 천장의 원인이 아니다. R10-a의 GIL 반증과
  합쳐 「16 중 9.5」의 후보가 GIL 스위치 간격·핸들러 슬롯 수 둘 다 지워지고 **프로세스당
  천장**(R10-a) 쪽만 남았다
- **2대(원격) 토폴로지 배선 자체** — `run_arms.py --remote-*`가 실전에서 처음 돌았고,
  버그 셋을 걸러 고쳤다(§5, 커밋 `bb0a8e54`·`42a0d927`)

**새로 연 것**

- 🔴 **원격 CPU 계측이 안 만들어졌다** — §4, 이슈 등록
- 🔴 **리허설도 `run_all.sh`를 그대로 태우면 AUTO_SHUTDOWN 대상이 된다** — 부하기(러너)에
  root SSH를 안 열어둬서 취소를 못 하고 `stop`으로 세이브·재기동했다. 그 바람에 부하기
  가동시간이 두 세그먼트로 쪼개졌고, `MANIFEST.txt`의 "인스턴스 가동 0.30시간"은 **마지막
  세그먼트만**이다 — 실제 총 가동은 약 71분(1차 ~43분 + 2차 ~28분)으로 더 크다. 이슈 등록
- 🔴 **커밋 라벨을 못 믿는 사례** — §5, 이슈 등록까지는 아니고 이 문서에 경고로만 남긴다
